# 115.简·测试 Test4

状态：Test only / 待海阔实机验证  
版本：`2026092109`

## 目标

继续只优化“其它小程序 magnet → 115 离线 → 播放”链，不改原版登录、m115 加解密、文件管理和个人网盘直链实现。

## 相对 Test3 的增强

1. BTIH 去重同时支持 40 位 hex 和 32 位 Base32 magnet，统一转为 info_hash 比较。
2. 完成任务首次识别主视频/选集后，以 `115MagnetResult_<info_hash>` 缓存播放结果。
3. 后续相同 magnet 再次调用可直接复用缓存，避免每次递归扫描目录。
4. 即使用户已经删除“离线任务记录”但保留网盘文件，仍可通过缓存直接播放/进入选集；单视频播放前会 `getFile()` 校验缓存是否失效。
5. 失败任务在当前任务聚焦页提供“删除失败任务并重新提交”。
6. 主视频识别新增剧集/分段命名识别：`S01E01 / EP01 / Episode01 / Part1 / CD1 / 第1集` 等；两个以上明显剧集文件强制进入选集，避免最大文件误播。
7. 多个视频在大小接近时继续进入选集；单主片明显大于第二候选时继续直放。
8. `115OfflineResult` 改为自然数字排序，`EP1 / EP2 / EP10` 不再按字符串错排。
9. 选集页把 `sample / preview / trailer / 试看 / 预告 / 花絮 / 广告 / 二维码` 等小视频单独归入“其它小视频 / 附带内容”。
10. 继续保留 `115Offline?add=` 作为其它小程序稳定调用入口；原“复制调用”修正为“复制磁链调用”。

## 实机验收

1. 覆盖导入 `115.简·测试`，原版 `115.简` 保持不动。
2. 用已完成的 `meyd-553` magnet：应聚焦当前任务，点击后直接播放 4.95 GB 正片。
3. 再次调用同一 magnet：不得新增重复任务；第二次播放应更快（命中结果缓存）。
4. 删除对应离线任务记录但保留网盘文件，再调用同一 magnet：应显示“已有网盘结果”并可直接播放。
5. 测一个多集资源：应进入选集页，顺序自然，不误播最大的一集。
6. 测失败 magnet：应出现“删除失败任务并重新提交”。
7. 验证最终播放仍由原版 `player.resolve` 返回 115 直链，UA/Header 无回归。
