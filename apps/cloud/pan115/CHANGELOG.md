### 新增：自定义离线保存目录

新增独立页面：

```text
115OfflineTargetPicker
```

能力：

- 从根目录逐级浏览 115 文件夹；
- 根目录 / 上一级导航；
- 当前目录直接新建文件夹；
- `设为这里`：把当前目录作为以后离线任务的默认保存目录；
- `恢复自动`：取消自定义目录，重新回到原来的自动优先级。

自定义目录本地状态：

```text
115OfflineCustomCid
115OfflineCustomName
115OfflineCustomTrail
```

优先级调整为：

```text
用户自定义目录
→ 海阔视界
→ 云下载 / 离线下载
→ 根目录
```

自定义目录只改变“新提交离线任务”和“失败任务重新提交”的目标目录，不改变现有已下载文件。

### 离线中心 V4

新增/调整：

- 顶部增加紧凑 `📂 改目录`；

- 长按继续支持：打开结果页、复制原链接、复制 info_hash、移除任务记录但保留文件；
- 失败任务“重新提交”会优先使用当前自定义目录；

## 1.2.1-test.12 / Build 2026092232 — 搜索目录跳转闭环（已实机验证）

最终确认当前 115Api 的规范化目录合同：

```text
isDirectory = true + fileId
→ fileId 本身就是目录 ID
```

原始 WebAPI 对象也可能表现为：

```text
!fid + cid
→ cid 是目录 ID
```

实机验证：`ipx-641` 保持 6 条结果、视频可播放、关键词摘要正常、目录可以进入。

状态：`device-validated-search-folder-navigation`。

- Test12 改为正确识别 `isDirectory + fileId`，目录点击闭环。

长期结论：**Test9 恢复的旧全盘搜索请求链属于不可破坏基线。不得根据 endpoint / aid / 认证模式重新拼“等价”搜索请求。**

## 对外磁链调用合同

固定：

```js
function playBy115(url) {
    if (!url) return "toast://未获取到磁力链接";
    return "hiker://page/115Offline?rule=115.简&page=fypage&add=" + encodeURIComponent(url);
}
```

禁止：

```text
magnet → 115Search?kw=
```
