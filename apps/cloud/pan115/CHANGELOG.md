
### 115 协议依据

复核 `SheltonZhu/115driver` 当前接口：

```text
GetUser()
→ user_name / face / user_id / vip / expire

GetInfo()
→ space_info.all_total
→ space_info.all_use
→ space_info.all_remain
→ login_devices_info
```

当前 115Api 对部分对象存在 camelCase 规范化，因此 UI 读取同时兼容 `userName/user_name`、`spaceInfo/space_info`、`allTotal/all_total` 等字段，不自行新增请求协议。

### 诊断与高级设置

普通页面继续隐藏技术字段。只有进入诊断页才显示：

- 当前规则版本；
- 115 Client 是否可创建；
- 海阔视界 / 云下载目录缓存 CID；
- 离线目录识别 mode；
- 文件排序/筛选状态；
- 离线筛选状态；
- 最近目标目录数量。

诊断摘要**明确不包含 Cookie、SEID、KID、二维码登录凭证等账号敏感数据**。

新增两个安全维护动作：

1. `重置界面状态`：只清理排序、筛选、最近目标目录等 UI 状态，不退出账号、不删除文件；
2. `重新识别离线保存目录`：只清目录 CID 缓存，下次显式提交离线任务时重新扫描，不删除任何目录/文件。

## 1.2.1-test.12 / Build 2026092232 — 搜索目录 `fileId` 语义修复（已实机验证）

搜索最终闭环：

- `ipx-641` 保持 6 条结果；
- 视频可播放；
- 关键词摘要纯文本；
- 搜索结果目录可正常进入。

关键根因：当前 115Api 规范化对象中，目录同样使用：

```js
fileId + isDirectory=true
```

因此：

```text
原始 WebAPI目录：!fid && cid        → 目录ID = cid
规范化115Api目录：isDirectory=true → 目录ID = fileId
```

**禁止再把 `fileId` 固定解释为普通文件 ID。**

## 长期协议与禁用项

外部磁链调用固定：

```js
function playBy115(url) {
    if (!url) return "toast://未获取到磁力链接";
    return "hiker://page/115Offline?rule=115.简&page=fypage&add=" + encodeURIComponent(url);
}
```

永久禁止/避免：

- magnet → `115Search?kw=`；
- 自行重写完整 115 magnet 协议层；
- 后台高频/并发轮询（历史事故曾导致 HTML 响应和“我的文件”空白）；
- 普通删除继续猜 `client.request()` 参数顺序；
- 重新改写 Test9 已恢复并实机证明工作的搜索请求链；
- 点击目录后另发一个猜测搜索请求恢复 ID；
- 把 `fileId` 固定解释为普通文件 ID；
- 普通页面常驻 Cookie/CID/hash/endpoint 等技术字段；
- 未经实机验证就标记完整 `deviceValidated`。
