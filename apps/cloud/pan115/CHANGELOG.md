## 1.2.1-test.12 / Build 2026092232 — 搜索目录跳转闭环（已实机验证）

最终确认当前 115Api 规范化目录使用：

```text
isDirectory=true + fileId → fileId 即目录 ID
```

原始 WebAPI 对象仍可能是 `!fid + cid → cid 为目录 ID`。

实机通过：`ipx-641` 保持 6 条、视频可播放、关键词摘要纯文本、目录可进入。

**Test9 恢复的旧搜索请求链是不可破坏基线。** 后续搜索只能改结果层/字段解释，不重新合成请求。

## 长期协议与禁用项

外部磁链固定：

```js
function playBy115(url) {
    if (!url) return "toast://未获取到磁力链接";
    return "hiker://page/115Offline?rule=115.简&page=fypage&add=" + encodeURIComponent(url);
}
```

永久禁止/避免：

- magnet → `115Search?kw=`；
- 自行重写完整 115 magnet 协议层；
- 后台高频/并发轮询；
- 普通删除猜 `client.request()` 参数顺序；
- 重写 Test9 已恢复并实机证明工作的搜索请求链；
- 点击目录后另发猜测搜索恢复 ID；
- 把 `fileId` 固定解释为普通文件 ID；
- 普通页面常驻 Cookie/CID/hash/endpoint 等技术字段；
- 未经实机验证就标记完整 `deviceValidated`。
