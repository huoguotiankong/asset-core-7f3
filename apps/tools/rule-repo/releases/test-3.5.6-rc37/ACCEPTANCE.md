# RC37 实机验收

1. 测试仓升级到 `3.5.6-rc37 / Build427`。
2. 第 2/3 次打开首页，速度不得明显慢于 Stable 3.5.5。
3. 点击 Pornhub：首次允许短暂显示“正在读取当前程序版本…”，随后详情必须出现实际 Stable/Test 卡片，不能是 0 个版本。
4. 返回后依次点 JavBus、JavDB、MyAv，行为相同；每次只加载当前程序 channels。
5. 再次打开刚访问过的程序详情，应优先复用本地 per-app cache。
6. 点击“检查版本”仍以当前程序自己的 `channels.json` 为真相源。
7. Stable 3.5.5 不升级，直到首页性能、详情、导入、自更新和同步全部通过。
