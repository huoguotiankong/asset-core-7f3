## 0.1.0-test.19 / Build 10119 — 首页重复分页、筛选分组与底部统计再修正

### Test18 实机反馈

1. 子板块筛选仍有排序项混入分类栏，例如“最新”等排序词在某些 URL 携带当前 `typeid` 时仍被错误识别成分类；
2. `scroll_button` 数量较多时海阔会自动出现右侧 `>` 并进入统一“请选择”弹窗，导致分类与排序选项再次混在同一个选择面板里；
3. 首页滚到子板块列表底部后，又继续追加了一整套搜索框、账号/签到/搜索/设置、话题和论坛分类，说明首页被 `fypage` 自动请求了下一页；
4. 用户要求首页子板块结束后即真正结束，不允许再重复整页内容；
5. 帖子目录的回复/观看等统计需要继续弱化，不影响当前作者、标题、摘要与双图卡片结构。

### Test19 修复

1. **首页彻底禁止自动分页重复**
   - `home()` 外层增加 `MY_PAGE` 守卫；
   - 只有第 1 页真正执行首页构建；
   - `MY_PAGE > 1` 直接返回空结果；
   - 解决“子板块已经到底，继续往下又出现搜索框和话题”的重复首页问题。

2. **分类与排序从横向按钮改成两个独立选择器**
   - 不再依赖大量连续 `scroll_button`；
   - 页面顶部只保留两个清晰入口：`分类：当前分类`、`排序：当前排序`；
   - 点击“分类”只出现当前子板块自己的分类列表；
   - 点击“排序”只出现全部主题 / 最新 / 热门 / 精华 / 按发帖 / 按回复等排序；
   - 使用项目指南已验证的 `select://` JSON 路由，避免 `$().select` 重载兼容问题。

3. **排序词即使携带 typeid 也不再进入分类**
   - `最新 / 热门 / 精华 / 按发帖 / 按回复 / 最新发表 / 最新回复` 等先按语义识别为排序；
   - 只有标题不是排序词时，`typeid/sortid` 才能进入分类集合；
   - 从解析层而不是仅靠 UI 层解决“排序跑进分类”的根因。

4. **统计信息继续弱化**
   - 保留卡片底部统计，不放回作者行、标题或摘要；
   - 统计改为 `text_1` 的次级 `desc`，避免抢占主标题视觉层级；
   - 回复 / 点赞 / 观看仍按真实解析结果显示。

5. **保持当前已正常能力**
   - mobile=2 列表优先与 PC 最小补图不变；
   - 普通帖子双图预览、在线视频双列不变；
   - 搜索、评论页、色花图片正文补图、文学标题不变；
   - 分类/排序/上一页/下一页继续 `refreshPage(false)`，不增加返回栈；
   - Stable / Latest / 根 `registry.json` 继续不建立。

## 0.1.0-test.18 / Build 10118 — 子板块筛选/排序与统计栏排版修正

### Test17 实机反馈

1. 普通帖子底部统计栏出现三个灰色按钮，占用空间仍明显；
2. 右侧统计内容直接显示了 `<small><fo...` 一类 HTML 源码，说明 `text_3` 不会按 Test17 的写法解析 HTML；
3. 子板块第一行分类与排序信息混在一起，例如“无码 / 有码 / 最新 / 热门 / >”；
4. 第一行出现多个勾选状态，无法清楚判断真正当前分类；
5. 第二行“最新 / 热门 / 精华 / 按发帖 / 按回复”方向正确，但末尾仍有 `>` 箭头占位；
6. 用户要求继续美化并保持每个子板块自己的分类与排序全部可用。

### Test18 修复

1. **统计栏不再使用三列空按钮**
   - 删除 Test17 的两个空 `text_3` + 一个带 HTML 的 `text_3` 方案；
   - 改为单条纯文本统计行：`💬 回复 / 👍 点赞 / 👁 观看`；
   - 不再输出 `<small>/<font>` 等 HTML 字符串，避免源码直接显示；
   - 统计仍位于卡片底部，不重新混回作者行或标题摘要。

2. **分类与排序严格拆成两条横向栏**
   - 第一条只负责当前子板块分类；
   - 第二条只负责“全部主题 / 最新 / 热门 / 精华 / 按发帖 / 按回复”等排序；
   - 行首增加“分类”“排序”标识，减少用户对两排含义的判断成本。

3. **清理官网筛选文本噪声**
   - 去掉官网链接文字自带的 `✓ / √ / ✔ / ●` 前缀；
   - 过滤 `> / » / › / 更多 / 展开 / 收起` 等控制按钮，不把它们当成筛选项；
   - 当前选中状态统一由原生页用 `●` 标记，不再混用站点原始勾选符号。

4. **修复分类与排序混排**
   - `typeid` 优先作为分类；
   - `sortid` 只有在标题不是“最新/热门/精华/按发帖/按回复”等排序词时才进入分类行；
   - 排序只接收明确排序标题以及 `filter/orderby/digest` 等真实排序参数；
   - 避免 Test17 中“有码 / 最新 / 热门”同时出现在分类行并多重选中的情况。

5. **选中状态更严格**
   - 分类按 `typeid/sortid` 的真实参数签名判断；
   - 排序按 `filter/orderby/digest` 判断；
   - 当前 URL 没有对应筛选参数时，仅默认第一项处于选中状态。

6. **继续保持已正常链路**
   - 每个子板块继续动态读取自身分类和排序，不硬编码固定板块；
   - 分类、排序、上一页/下一页继续 `refreshPage(false)` 原页刷新，不增加返回栈；
   - mobile=2 主题卡片优先、PC 最小补图继续保持；
   - 在线视频双列、普通帖子双图预览、色花文学标题、色花图片正文补图、评论页、搜索均不回退；
   - Stable / Latest / 根 `registry.json` 继续不建立。
