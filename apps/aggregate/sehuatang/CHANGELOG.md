## 0.1.0-test.16 / Build 10116 — 评论分离、图片正文顺序与目录信息美化

### Test15 实机反馈

1. 色花图片帖子已经能从手机端整页补出大量真实图片，但补图发生在所有回复之后，导致正文图片被评论打断，顺序不符合手机网页版；
2. 用户希望所有分类的帖子详情页把“复制链接”改成“评论页”，详情页正文与评论区分离，点击评论页后再查看评论/进入回复；
3. 普通帖子目录里“观看量 30756 / 评论数 41 / 点赞数”等数字混在标题或简介前部，影响第一视觉层级；
4. 作者头像、作者名、版主/楼主标签和发布时间应继续保持独立一行，统计信息不能重新混回作者行或正文摘要；
5. 当前手机端卡片的标题、摘要、双图预览、页内刷新翻页、搜索等链路已经有可用成果，本轮只做信息层级和详情结构优化，不回退这些能力。

### Test16 修复

1. **帖子正文与评论彻底分离**
   - `shtThread` 详情页只渲染楼主正文、正文图片、视频入口和磁链云播；
   - 不再在正文后直接连续铺所有回复；
   - 详情页新增独立“评论页”按钮，并新增 `shtComments` 原生页面；
   - 评论页只显示回复楼层，并提供“参与回复”入口跳官网回复页；
   - 原“复制链接”快捷按钮由“评论页”替换，磁链区域里的“复制磁链”仍保留。

2. **色花图片正文图移动到评论之前**
   - 楼主正文仍按 mobile=2 正文 DOM 顺序解析；
   - 若楼主正文容器没有图片，色花图片 group 3 立即从手机端渲染整页提取真实图片；
   - 补出的图片直接接在楼主正文之后，再显示视频/磁链/评论入口；
   - 不再等所有回复处理完成后才补图，因此不会出现“回复 1~7 后面才开始出现 73 张图片”。

3. **普通目录元数据重新分层**
   - 作者头像、作者名、版主/楼主角色、发布时间继续使用独立 `avatar` 行；
   - 标题、正文简介、1~2 张预览图保持原有手机端卡片层级；
   - 回复数 / 点赞数 / 观看量从摘要开头剥离；
   - 统计信息移动到卡片底部，使用浅灰、小号、右侧视觉弱化样式，避免抢标题和预览图的视觉焦点。

4. **统计字段提取**
   - 优先识别“回复/评论/查看/浏览/观看/点赞”带标签的数字；
   - 对当前站点手机端常见的 `回复数 点赞数 观看量` 三连数字增加兜底识别；
   - 目录摘要继续清除这些数字，避免出现 `23 0 20886 ...` 一类开头污染。

5. **在线视频与其它分类保持差异化**
   - 在线视频 group 1 继续使用 `movie_2` 双列视频卡片；
   - 普通 BT / 图片 / 文学 / 综合板块仍使用作者行 + 标题 + 简介 + 预览图卡片；
   - 对设备分组缓存失效时，增加 `中文字幕 / 国产成人自拍 / 亚洲视频 / 经典三级 / 在线视频` 等名称兜底识别，不把“高清中文字幕”等原创 BT 板块误判为在线视频。

6. **保持当前已验证链路**
   - 搜索继续继承 Test11 已实机正常的 `search.php` 表单提交 + `searchid`；
   - 普通板块继续 mobile=2 优先；
   - 翻页继续 `putMyVar + refreshPage(false)` 原页刷新，不增加返回栈；
   - 115 / 迅雷 / PikPak / 复制磁链、BTIH 去重、视频嗅探、访问状态/Cookie 均继续保留；
   - Stable / Latest / 根 `registry.json` 继续不建立。
