# 色花堂海阔小程序

当前仅发布 **0.1.0-test.1 / Build 10101**，用于实机验证色花堂 Discuz 移动站的基础浏览与磁链云播调用。

## Phase 1

- 原生：首页搜索、登录、签到、论坛分区。
- 原生：板块主题列表、帖子正文与图片。
- 原生：主题搜索；失败时保留网页搜索兜底。
- 原生：自动识别帖子中的 `magnet:`。
- 云播：115.简、迅雷、PikPak、复制磁链。
- WebView：登录、验证码、签到、回复。

## 暂不进入 Test1 的功能

原生签到、原生回复/编辑、收藏历史、只看楼主、附件下载、自动多域探活、个人中心、提醒/消息等，等待 Test1 实机确认 Cookie 与页面模板后逐项加入。
