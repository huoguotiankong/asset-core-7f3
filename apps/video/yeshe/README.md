# 夜社短剧

自用远程版海阔视界小程序。当前仅发布 Test 通道，不建立 Stable。

## 产品范围

- 夜社短剧首页：短剧热门类型、最近更新、三列内容卡。
- 全站分类：视频 / 动漫 / 有声 / 漫画 / 写真 / 小说，优先从当前站点导航动态映射分类 URL。
- 搜索：先解析站点搜索表单，再使用有限兼容路由。
- 详情：视频选集、多线路、图集、小说正文、章节入口、相关推荐。
- 播放：直链/页面媒体标签 → player JSON → iframe 一跳 → video:// 嗅探 → 网页兜底。
- 本地收藏、浏览历史、搜索历史。
- 网站登录/签到/社区先通过当前站点 Web 会话复用，后续根据实机协议逐步原生化。
- 动态域名：last-good 优先；失效后通过 yeshe.tv / ysurl.win 与用户当前入口恢复。

## 当前状态

0.1.0-test.1 / Build10101。属于新程序第一版，分类选择器、搜索路由、非视频内容结构和真实播放链必须以海阔实机结果继续冻结；未验证前不得晋级 Stable。
