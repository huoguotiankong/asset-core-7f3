# 视色（Shise）

自用远程版海阔视界小程序。当前仅发布 Test 通道，不存在 Stable。

## 产品范围

- 首页原生视频卡片与分页加载。
- 分类：读取当前站点有效分类并进入可分页内容列表。
- 搜索：片名 / 编号 / 关键词。
- 人物：从当前内容链识别人物，人物详情支持 `fypage` 持续加载关联作品。
- 独立详情页：封面、编号、日期、人物、分类、系列/厂牌、普通标签、简介、相关推荐。
- 播放：优先使用海阔 `video://` 运行时嗅探，并通过 `videoRules` 精准匹配视色 `s1.playhls.com/m3u8.php?` 正片请求；同时排除已知广告域名/请求特征。
- 播放诊断：播放器页精准嗅探 / 详情页精准嗅探 / 宽松 HLS 三档。
- 收藏 / 历史入口、X5 会话验证、Cookie 读取与页面缓存兜底。

## 当前状态

`0.1.0-test.8 / Build 10108`。

当前重点实机验收：

1. 正片播放是否能由精准 playhls 嗅探稳定命中，且不再命中短广告。
2. 人物详情向下加载是否能突破第一页 12 条作品。
3. 详情元数据的“人物 / 分类 / 系列厂牌 / 编号 / 日期 / 标签”是否归类正确。

上述核心链全部通过前不得晋级 Stable。
