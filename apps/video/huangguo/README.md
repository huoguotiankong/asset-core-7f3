# 黄果短剧

海阔视界自用远程版。当前仅发布 Test 通道，Stable 尚未建立。

## 当前页面

- 首页：搜索、推荐、最新、AI短剧、AI漫剧、AI换脸、AI魔改、继续观看。
- 片库：12 个题材标签，同页切换。
- 榜单：热播、推荐、潜力。
- 专题：精品高分、灵异诡事、魔改电视剧。
- 搜索：历史词 + 搜索结果。
- 详情：Hero、简介、标签、选集、结构化播放、相关推荐。
- 我的：本地收藏、观看历史。
- 设置：布局、线路重发现、本地数据、诊断。

## 当前数据策略

网页 HTML 为首版 P0 数据源；业务域名自动发现并缓存 last-good。APK 中发现的 APP API 只作为后续协议研究资料，未确认签名/设备指纹/加密合同前不进入 Runtime。
