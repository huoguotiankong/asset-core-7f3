# 我的规则仓库 3.5.0-rc12 实机测试说明

## 目标

RC12 是基于 RC11 实机截图继续进行的 UI Luxe 迭代，正式版 Stable 3.5.1 保持不动。

本轮不扩张底层能力，重点处理视觉密度、信息层级与恢复体验：

- 程序列表从 `movie_1_left_pic` 恢复为更紧凑的 `icon_1_left_pic`，避免图标过大、列表过长。
- 首页保持 Hero / 五项导航 / 主分类 / 四项状态 / 程序列表的产品结构。
- 分类页采用更明显的主分类卡片，高级标签、运行方式、排序和批量管理继续折叠。
- 搜索页只常驻“全部 / 有更新 / 收藏”，远程/本地收进运行方式筛选。
- 详情页四项核心信息改为只读状态卡，主操作仍为打开 + 更新/导入。
- 正式版/测试版二级页删除重复 CTA 和大段版本说明，直接点击版本卡导入。
- 双版本元数据读取逻辑改为 RC12 自包含：云端读取 → 本地缓存 → 内置恢复元数据，不再依赖历史版本模块残留。
- 设置页改为“同步与更新 / 数据管理 / 关于”三组动作卡片，删除长篇说明和四组清理按钮。
- 更新中心改为四项常用操作卡 + 待更新列表。

## 实机重点验证

1. 首页程序卡片是否比 RC11 明显紧凑，并更接近参考图。
2. 首页四项状态切换是否正常。
3. 分类主分类 / 子分类 / 高级筛选展开收起是否正常。
4. 中文搜索和标签跳转是否保持正常中文。
5. 双版本页在正常联网和版本元数据读取失败时都能保留正式/测试恢复入口。
6. 设置页自动检查、缓存、同步、备份、恢复、清理均可操作。
7. 更新中心能进入测试版更新并安全同步目录。
8. 任意页面异常不得清空最后一个有效 manifest。

## 发布边界

- Stable：3.5.1 / build 360，不变。
- Candidate/Test：3.5.0-rc12 / build 363。
- Test Shell：1.0.11-test。
- RC12 必须通过 Release Guard + 海阔实机关键路径验证后，才允许考虑晋级正式版。
