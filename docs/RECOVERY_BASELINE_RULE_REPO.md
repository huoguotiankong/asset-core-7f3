# 我的规则仓库正式恢复基线

正式版必须独立于测试版保持可用，并始终具备以下能力：

1. 能正常打开云仓库首页。
2. 能进入“我的规则仓库”二级版本页。
3. 二级页同时展示正式版与测试版入口。
4. 测试版启动失败时，可从正式版重新导入测试版覆盖恢复。
5. 正式版自身升级/回退不依赖测试版状态。
6. 正式版只有在对应 Candidate 通过实机关键路径验证后才晋级。

“我的规则仓库”是默认唯一允许 Stable/Test 使用不同程序名并同时安装的程序，因为它承担自举恢复职责。其它小程序 Stable/Test 默认保持同名，通过海阔同名覆盖切换版本。

当前恢复基线：Stable 3.5.1 / build 360 / Shell 1.5.1 / Manager 2.0.2。
