# 我的规则仓库 RC11 UI Pro

版本：3.5.0-rc11  
Build：362  
通道：Test / Candidate  
正式版保持：Stable 3.5.1 / build 360

## 本轮目标

根据海阔实机截图继续向产品参考图靠拢。本轮优先解决视觉层级、首页状态表达、分类信息过载、中文搜索编码和双版本页完成度，不新增高风险底层能力。

## UI / UX 改动

- 首页重新采用“Hero → 五项导航 → 主分类 → 四项状态卡 → 我的程序”的产品结构。
- 四项状态卡为：全部、已记录、可更新、收藏，可直接切换程序视图。
- 程序卡片调整为更接近应用列表的 `movie_1_left_pic`，突出名称、版本/分类/状态和一句功能说明。
- 分类页默认只展示主分类和当前子分类；能力标签、运行方式、排序和批量管理统一收进“高级筛选”。
- 切换主分类时自动清理旧子分类/标签，避免跨分类残留条件造成空结果。
- 搜索页新增安全关键词解码，修复从 `kw=` 跳转时中文显示为 `%E6%...` 的问题。
- 搜索页保留最近搜索、热门标签和最近使用，主界面不再先堆大量功能说明。
- 程序详情将“版本 / 状态 / 分类 / 更新时间”整理为四项核心信息；打开和导入/更新继续作为主操作。
- 双版本中心按“正式版推荐 → 测试版抢先体验 → 恢复保障”重新分区，并恢复明确的“导入正式版 / 导入测试版”CTA。
- 双版本元数据继续使用云端成功缓存 + 本地缓存 + 我的规则仓库内置恢复数据三层兜底。

## 安全边界

- 不修改 Stable 3.5.1。
- 保留 RC8 事务式同步、多镜像读取。
- 保留 RC9/RC11 运行时 API 契约门禁。
- 测试版仍使用独立名称“我的规则仓库·测试版”，确保测试失败后可以从正式版恢复。

## 实机验收重点

1. 首页四项状态卡是否正常一行显示，程序列表是否比 RC10 更接近参考图。
2. 分类页默认是否明显更清爽，高级筛选展开/收起是否正常。
3. 从详情标签进入搜索后，搜索框必须显示正常中文，不得再出现 `%E6%...`。
4. 我的规则仓库双版本页必须同时存在正式版和测试版，并可分别导入。
5. 程序详情的主操作、信息区、标签区和快捷操作层级是否清晰。
6. 首页同步失败时仍不得清空最后有效目录。
