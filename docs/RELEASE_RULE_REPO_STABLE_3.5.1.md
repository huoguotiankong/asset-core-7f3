# 我的规则仓库 Stable 3.5.1

日期：2026-08-20

## 发布结论

RC9 / build 359 已完成海阔实机恢复验证，正式晋级为 Stable 3.5.1 / build 360。

## 晋级理由

- 测试版 Fresh install / Recovery Shell 已恢复正常启动。
- 修复 RC6 UI 重构遗漏 `pushSpacer`、`pushEmpty`、`formatTime` 等共享基础 API 的问题。
- 保留 RC8 的事务式同步：新目录获取与校验成功后才替换旧缓存，失败时继续使用最近有效目录。
- 保留 Manager 2.0.2 多镜像加载链。
- 保留正式版 / 测试版二级版本入口；“我的规则仓库”作为唯一默认双名称例外，可同时安装正式版和测试版。
- 新增运行时 API 契约与 Release Guard 静态契约检查，降低模块重构时公共 API 被误删的风险。

## 恢复策略

正式版必须始终具备进入云仓库并重新导入测试版的能力。测试版发生启动故障时，不要求测试版本身可自救；用户可直接打开正式版，在“我的规则仓库”二级版本页重新导入测试版覆盖恢复。

## 当前通道

- Stable：3.5.1 / build 360 / Shell 1.5.1 / Manager 2.0.2
- Test：3.5.0-rc9 / build 359 / Shell 1.0.8-test / Manager 2.0.2

下一轮测试版从 RC10 开始继续进行 UI/UX 强化，Stable 3.5.1 作为恢复基线保持不动，直到新的 Candidate 完成实机验证。
