# 我的规则仓库 3.5.0-rc10 测试版说明

状态：Candidate / Test  
Core：3.5.0-rc10  
Build：361  
Shell：1.0.9-test  
正式版保持：Stable 3.5.1 / build 360

## 本轮目标

RC10 不继续堆大量新功能，重点提升产品完成度、恢复能力和 UI/UX 一致性。

## 重点改动

- 双版本二级页重构：正式版优先、测试版次级、当前运行版本明确；整张版本卡直接导入。
- 双版本元数据增加本地缓存；云端暂时不可读时优先使用最近一次有效版本信息。
- “我的规则仓库”额外内置当前正式/测试恢复元数据，避免版本描述读取失败时失去恢复入口。
- 首页进一步降噪：去掉一次性“界面焕新”等干扰信息，保留品牌、主导航、分类、状态筛选、排序/同步和程序列表。
- 普通程序详情压缩重复信息，保留“打开 / 更新或导入”两个主操作和四项次级操作。
- 更新中心改为“版本更新 + 安全同步”两条主路径，不再长期罗列无更新程序。
- 修复旧更新中心仍存在 `clearManifestCache()` 后再联网的危险路径，统一改用事务式 `syncManifest()`。
- 错误文案增加用户化处理，技术错误不再直接抢占主界面。
- 继续沿用 RC8 安全同步、多镜像读取和 RC9 运行时 API 契约门禁。

## 实机重点验证

1. 首页、分类、搜索、更新、设置全部可打开。
2. 点击“我的规则仓库”进入双版本页；正式版 / 测试版卡片均可正常导入。
3. 双版本页能正确标记当前运行版本。
4. 首页“同步”和更新中心“同步程序目录”连续执行，不得清空最后有效目录。
5. 网络波动时双版本页仍能使用缓存或内置恢复元数据。
6. 测试版更新页能识别 RC10，并可回退到 RC9。

## 晋级条件

RC10 仅进入 Test/Candidate。必须完成 Release Guard 和海阔实机关键路径验证后，才考虑晋级新的 Stable。
