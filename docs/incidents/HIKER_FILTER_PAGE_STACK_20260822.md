# 海阔分类/筛选连续开新页事故与统一修复模式（2026-08-22）

状态：已在麻豆AI `2.7.0-test.2` 首次按统一模式修复，待实机回归后继续推广。

## 1. 典型症状

同一“片库 / 分类 / 搜索 / 我的”等功能页里，用户每点击一次：

- 一级分类；
- 二级分类；
- 排序；
- 筛选；
- Tab；

程序都返回新的：

```text
hiker://page/<samePath>?rule=&simple=true&...
```

结果是视觉上像“切换了筛选”，实际上每次都向页面返回栈压入一个新的相同页面。连续点击多次后，按返回键必须逐层退很多次。

麻豆AI `2.7.0-test.1` 实机截图同时暴露了另一个关联问题：少量一级栏目使用 `scroll_button`，窄屏出现无意义 `>` 溢出入口；动态分类又被原样平铺，导致页面层级乱、密度失控。

## 2. 根因

把两种完全不同的交互混在了一起：

```text
Navigation：进入一个新的业务页面
State Change：在当前页面改变分类/排序/筛选状态
```

`hiker://page/...` 应承担 Navigation，不应默认承担同页筛选 State Change。

另一个常见根因是：

```text
URL query 参数
> 页面可变状态
```

如果页面每次刷新都优先读取最初 URL 中的 `menu/cat/sort`，即使按钮已经 `putMyVar()` 写了新值，也可能被旧 query 再次覆盖，表现为“按钮点了但筛选又跳回去”。

## 3. 统一正确模式

### 3.1 首次进入页面：允许导航一次

```text
首页/详情/快捷入口
→ hiker://page/library?rule=&simple=true
```

需要深链初始状态时，优先在进入前写入页面状态；query 仅作为一次性 seed，不作为之后每次刷新都拥有最高优先级的状态源。

### 3.2 页面内部切换：原地更新

优先：

```js
$('#noLoading#').lazyRule(function(key, value){
    putMyVar(key, value);
    refreshPage(false);
    return 'hiker://empty';
}, key, value)
```

更细粒度且结构稳定的页面，可进一步使用：

```text
updateItem / deleteItemByCls / addItemAfter
```

只刷新目标区域。

### 3.3 返回栈验收

连续切换 10 次分类/排序/筛选后：

```text
按一次返回
→ 直接退出当前功能页
```

如果要退 10 次，说明仍然把 State Change 写成 Navigation。

## 4. 组件选择

- 固定 2/3/4 个一级栏目：优先 `text_2 / text_3 / text_4` 等宽布局。
- 少量确实需要横向滚动的入口：才使用 `scroll_button`。
- 数量较多、需要一屏自动换行的主题分类：使用 `flex_button`。
- 窄屏出现 `>` 溢出入口时，不要继续硬塞 `scroll_button`；应调整信息层级或换组件。
- 同一选中状态只使用一个主要视觉信号。已经用浅色背景区分时，不再叠加富文本红字、圆点或星号。

## 5. 动态分类不能直接替换稳定分类骨架

当接口分类存在偶发少项、排序波动、内部项或实验项时，不建议：

```text
remote non-empty
→ 直接完全替换 fallback
```

更稳定的长期模式：

```text
已验证用户可见分类骨架
+ 当前动态接口数据
→ CatalogAdapter 合并/清洗/去重/排序
→ Renderer
```

原则：

- 已验证 ID/一级归属/基础顺序可作为稳定骨架。
- 动态接口负责更新名称、状态和追加新的真实分类。
- 动态接口偶发少返回一项，不应让已验证分类立刻从 UI 消失。
- 新增真实分类仍应可追加，不能退化成永久截图白名单。

## 6. 麻豆AI对应修复

`2.7.0-test.2 / Build27002`：

- 视频/短剧在同一片库原地切换。
- 原创/国产/字幕改固定等宽三栏。
- 主题分类使用 CatalogAdapter + `flex_button`。
- 高级筛选改四栏：默认 / 近1月 / 20分+ / 点赞。
- 分类/排序/筛选统一 `lazyRule → putMyVar/clearMyVar → refreshPage(false)`。
- 首页进入指定片库分类时只导航一次，并先写入片库状态。

## 7. 后续适用范围

凡海阔小程序出现：

- 分类页；
- 搜索范围切换；
- 收藏/历史 Tab；
- 排序与筛选；
- Provider 切换；
- 章节范围切换；

都应先判断它是 Navigation 还是 State Change。属于当前页状态变化时，默认采用本 Incident 的原地更新模式。
